# A1 — Installed app: Settings Install app row (S55)

Amends the ratified [standings-search-settings design](../DESIGN.md) (ratified 2026-10-14) for ADR-023's quiet install prompt. Story **S55**.

**Adds:** an **App** group in Settings, above Account, with one line of description and an `Install app` text link.
**Overrides:** nothing.
**Repeals:** nothing.

Source: https://www.figma.com/design/wqGKEFlvyxq0ObWZhRJdPF — section "O — Installed app (S55, ratified 2026-10-21)", live file as edited in the S55 session (no named version).

## Frames

Every export is a 1× PNG of the Figma frame with the same name, built from the ratified `settings-mobile` / `settings-desktop` frames and their Account group.

## Decisions

Recorded as the owner stated them (2026-10-21). The owner answered the agent's numbered questions; their numbering shifted in the chat, and they restated the mapping (the owner's 1, 2, 3 and 4 are the agent's 1, 3, 5 and 6; they added that 2 and 4 are also fine), so the agent's Q1 = update notice, Q2 = offline marker, Q3 = never-viewed room offline, Q4 = standalone layout, Q5 = Install row, Q6 = ratify.

- **Install row** — an App group above Account with a quiet `Install app` link, no banners or pop-ups; the row is hidden once the app is installed and where the browser cannot install it. Settings is signed-in only (ADR-027), so signed-out visitors get only the browser's own install prompt (Q5, owner: "Sounds good").
