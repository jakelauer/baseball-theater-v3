# A2 — Search retitled, search playback, iOS install steps (S56)

Amends the ratified [standings-search-settings design](../DESIGN.md) (ratified 2026-10-14) and its [A1](A1.md). Story **S56**.

**Adds:** a search result playing in a modal over the results page, with a link to its game; the Install app row's iPhone/iPad state with Share → Add to Home Screen steps.
**Overrides:** the Search page title — "Search Highlights", box hint "Search highlights…" (Search is highlights-only); A1's rule that the Install row is hidden where the browser cannot install — on iOS it shows the steps instead.
**Repeals:** nothing.

Source: https://www.figma.com/design/wqGKEFlvyxq0ObWZhRJdPF — section "P — Navigation, signed-out shell, leftovers (S56, ratified 2026-10-21)", live file as edited in the S56 session (no named version).

## Decisions

Recorded as the owner stated them. The 2026-10-19 intake answers were "accept your rec" except where quoted (S56 Gap). On 2026-10-21 the agent restated the drawn choices as numbered questions; the owner answered: "For 5, a video search result should play in a modal from the results page, and a link to the game should be on the modal." and "The rest are fine".

- **Search result** — "a video search result should play in a modal from the results page, and a link to the game should be on the modal" (2026-10-21). This supersedes the 2026-10-19 answer that it opens the game's Videos tab.
- **Search title** — Search is highlights-only and retitled (2026-10-19); the title "Search Highlights" with hint "Search highlights…" (2026-10-21: "The rest are fine").
- **iOS install** — "iOS should show the share instructions" (2026-10-21); the steps as drawn (2026-10-21: "The rest are fine").
