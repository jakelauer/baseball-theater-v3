# A1 — Installed app: offline game rooms (S55)

Amends the ratified [game-rooms design](../DESIGN.md) (ratified 2026-10-14) for ADR-023's offline reading. Story **S55**.

**Adds:** a game room read offline with its age marker; a room never opened while online, shown offline.
**Overrides:** nothing.
**Repeals:** nothing.

Source: https://www.figma.com/design/wqGKEFlvyxq0ObWZhRJdPF — section "O — Installed app (S55, ratified 2026-10-21)", live file as edited in the S55 session (no named version).

## Frames

Every export is a 1× PNG of the Figma frame with the same name, built from the ratified `box-mobile` and `room-empty-mobile` frames and `notice-banner` `438:2959`.

| Export | Pairing | What it shows |
| ------ | ------- | ------------- |
| `room-offline-mobile.png` | mobile | Box room offline: `notice-banner` under the game top bar reading "You're offline. This game as of 7:42 PM — 18 min ago." (no action, no dismiss); content as saved; footer "Offline · saved 18m ago · baseball.theater". |
| `room-offline-unviewed-mobile.png` | mobile | A room never opened, offline: the "You're offline." banner, tabs still shown, an empty content area with **no explanation**; footer "Offline · baseball.theater". |

## Decisions

Recorded as the owner stated them (2026-10-21). The owner answered the agent's numbered questions; their numbering shifted in the chat, and they restated the mapping (the owner's 1, 2, 3 and 4 are the agent's 1, 3, 5 and 6; they added that 2 and 4 are also fine), so the agent's Q1 = update notice, Q2 = offline marker, Q3 = never-viewed room offline, Q4 = standalone layout, Q5 = Install row, Q6 = ratify.

- **Offline marker in rooms** — same banner and footer as the offline scoreboard, naming the game copy's time and age; Hide Scores still applies (Q2, owner: "2 and 4 are also fine").
- **Never-viewed room offline** — no explanatory copy; the room shows only the offline banner over empty content (Q3, owner: "Remove the explanation about why the tab content isn’t there. Partly bc it’s confusing and partly bc the tab data is very likely to be all or nothing for all visible tabs").
