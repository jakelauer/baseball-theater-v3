# A3 — The game rooms with Hide Scores on (S57)

Amends the ratified [game-rooms design](../DESIGN.md) (ratified 2026-10-14) and its [A1](A1.md) and [A2](A2.md). Story **S57**.

**Adds:** each room's state with Hide Scores on: Live, Box, Plays, the Runs view and Recap; the footer reads "Scores hidden in settings · baseball.theater".
**Overrides:** nothing drawn before; the rooms had no Hide Scores state.
**Repeals:** nothing.

## Decisions

Recorded as the owner stated them. On 2026-10-21 the agent restated the drawn choices as numbered questions; the owner answered each in turn, stating the principle: "FYI the point of this is to avoid spoilers for people who want to experience the game their own way, but if they’re looking at game details they clearly want the info".

- **Live** — drawn as asked (answer: "Ok"); asked again whether game details should show the score: "Hide the score". The batter's line shows, as on Plays.
- **Box** — "The box can tension the way it is normally" (read as "function": Box is unchanged by Hide Scores).
- **Plays** — "The batter’s line can stay"; the linescore: "Hide the score and any innings, and R/H/E".
- **Runs view** — "The Runs view can stay as is": kept, with the score after each scoring play hidden as drawn.
- **Recap** — "They can read the recap but we don’t want to show the title to them"; the headline is replaced with "Recap" (answer: "Recap").
