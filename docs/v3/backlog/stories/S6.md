**Acceptance criteria** (checks `scripts/verify-S6.sh` performs)

1. `GET` and `PUT /api/v1/me/settings` are in `ApiRoutes` and the spec: 401 without a session; with `dev:test-user`, `PUT` then `GET` round-trips the document; a `PUT` with an older `version` is ignored (apply-if-newer, ADR-022); a validly signed session whose uid has no account (deleted, S77) gets 401 on both, so a stale session can't write settings back after a deletion (ADR-028; added by the 2026-10-23 backlog review). `pnpm api:breaking` exits 0 (functions tests).
2. A `SettingsRepository` port in `packages/ports` with an in-memory adapter passes a new case in the S46 contract suite and S76's deletion case; it is registered in S76's personal-data registry as `BT database: settings` (ADR-028's inventory row) and labeled `personal` in the classification manifest (tests). (ADR-028 registration added by the 2026-10-23 backlog review.)
3. `web/src/settings/store.ts` is a Zustand store read with `useSettings()` and written through named setters (`setFavoriteTeams`, `setOpensFirst`); setters save to the account. It hydrates from the account after sign-in and resets to the house defaults on sign-out (tests). Its persisted (cache) copy goes through `web/src/storage/` under a key labeled personal, so S76's clear-all removes it on sign-out (test), and `git grep -nE 'localStorage|sessionStorage|indexedDB' web/src -- ':!web/src/storage/'` is empty. (Re-scoped by the 2026-10-23 backlog review: the old check, "`git grep -n localStorage web/src` hits only that module's persistence config", fails once S76 moves the session token into `web/src/storage/`.)
4. Settings renders the Game List / Game Detail / Account group headings, one column at `mobile` and two at `medium` / `desktop` (RTL via `variant`). The Account group (standings-search-settings A3) shows "Signed in as {email}" with the session's email and a "Sign out" link (an anchor-styled control, not a button) that calls `useSession().signOut()` (RTL); it renders no Patreon row until the Patreon link theme lands. (Re-scoped by the 2026-10-22 design intake.)
5. The Favorite Teams dropdown sets favorites; after a remount (and a fresh store hydrated from the account) the choice is still selected (RTL).
6. Opens First offers exactly Videos / Live / Box; `GamePage` opens that room when the game's phase offers it, else `resolveRoom`'s fallback (test). Signed out, games open on the house default.
7. `web/src/` contains no `presentationProfile` / `PresentationProfile` (VISUAL-DESIGN §5a), and no "magic link" or "passkey" text (A3 repeals magic-link sign-in; no passkeys at launch, ADR-019) (case-insensitive grep).
