**Gap:** `docs/v3/LAWS.md` (S84) lists four requirements that should hold on every commit but that only individual graders check, by hand, for the files their own story touched: P1 only `web/src/layout/` reads the viewport (`useMediaQuery`, `hiddenFrom`, `visibleFrom`; ADR-014 rule 8 — checked by S6, S40, S59, S60, S83), P3 the web app never calls MLB directly (ADR-002 — S16), P5 no personal data (emails, exports) in logs (ADR-028 — S77, S80), and P8 `pnpm verify` starts no browser (S81). Nothing stops a later change from breaking any of them. Asked which proposed laws a story should enforce, the owner answered (2026-10-28): *"Yes: P1, P3, P5, P8."* and placed the story before S79. Inserted by the owner, 2026-10-28.

**Impact:** Before S85, four rules the app depends on — screens size themselves in one place, the browser never talks to MLB, nobody's email ends up in a log, and the everyday checks never need a browser — were only checked when a story happened to look. S85 impact: all four are checked automatically on every change, so breaking one fails the build.
